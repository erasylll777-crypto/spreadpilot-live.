# SpreadPilot Live — запуск

Адаптивный read-only сканер межбиржевых цен. Бэкенд Node.js + Express + CCXT, фронтенд — HTML/CSS/JS. Используются публичные рыночные API; ключи бирж не нужны. Автоматические сделки не выполняются.

## Требования
- Node.js 20 или новее
- Подключение к интернету

## Запуск локально
```bash
npm install
npm start
```
Откройте http://localhost:3000

## Как рассчитывается маршрут
- Покупка по `ask`, продажа по `bid` (не по `last`).
- Спред = `(sell bid - buy ask) / buy ask * 100`.
- Оценка прибыли учитывает введённый размер позиции, комиссию сделки на обеих сторонах и вручную заданную комиссию вывода.
- Это предварительная оценка. Глубина стакана, проскальзывание, риск перевода, funding/прочие расходы и доступность сетей не проверяются.

## Настройки сервера
Переменные окружения:
- `PORT=3000`
- `CACHE_MS=5000`
- `REQUEST_TIMEOUT_MS=8000`

## Безопасность
- Не добавляйте API-ключи в frontend, URL, Git или этот проект.
- Публичные эндпоинты используются только для чтения котировок.
- Не включайте права торговли или вывода, если в будущем будете добавлять приватные API. Для следующего этапа предпочтительны отдельный серверный secret store, минимальные права, IP allowlist, rate limits и аудит.
- В production используйте HTTPS, reverse proxy, мониторинг, ограничение запросов и нормальную обработку ошибок.
- Вводимая комиссия вывода — ручное значение, а не тариф биржи из API.
- Список бирж — список интегрированных адаптеров, не буквально все существующие биржи. CCXT/биржевые API и доступность активов могут меняться.

## Что добавить перед production
1. Order-book depth / VWAP на выбранный объём.
2. Биржевые торговые комиссии с учётом уровня пользователя.
3. Реальная доступность сети и депозитов/выводов для конкретного актива (обычно приватный API или отдельный проверенный источник).
4. Свежесть котировок и защита от stale/outlier data.
5. Тесты расчётов, наблюдаемость, ограничения нагрузки, Docker/deployment.
6. Валютная нормализация: `amount` — размер позиции в котируемой валюте пары, а не универсально USD для любой пары.

## API
- `GET /api/health`
- `GET /api/exchanges`
- `GET /api/scan?symbol=BTC%2FUSDT&amount=1000&tradeFeePct=0.1&minSpreadPct=0&withdrawalFee=1&exchanges=binance,bybit,okx`

Ошибки отдельных бирж возвращаются в `tickers[].error`; сканер продолжает работу с доступными котировками.


## Размещение на Render
В проект добавлен `render.yaml` с базовой конфигурацией Render. Подключите GitHub-репозиторий с этими файлами к Render и создайте Web Service. Перед реальным постоянным использованием проверьте тариф и ограничения бесплатного плана: бесплатные сервисы могут засыпать после периода бездействия.
